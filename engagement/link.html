Explain the difference between an absolute link and a relative link. Why would you use a relative links?

An absolute link gives the full web address of a page and it tells the browser exactly where to go including the website name. A relative link is the page or file within my own website or folder and it does not include https or website name.

3 Rules with relative links

1. siblings: use file name

2. child: folder/filename

3. aunt/uncle: ../links.html
