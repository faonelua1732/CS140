CSS

CSS stands for Cascading Style Sheets

What is the difference between inline, embedded and external CSS?

Inline css is written directly inside an HTML element using the style. Embedded css is written inside style tag of the HTML file. External CSS is written in a separate css file that is link to your html and every changes you make in this file will show on your web page.

Explain why you should only use external CSS?

Because it makes it easier to edit or change the style of you website especially if you have lot of web pages.

What is a selector used for?

the selector tells css how you want to style you web page
