When do you use a table?

Use a table when you need to organize related information into rows and columns like the class schedule.

When do you need not use a table?

Dont use a table just to arrange the layout or appearance of a webpage cause we can use css for that.

When do you need to do extra work for table accessibility?

We may need to do extra work when a table has merged cells or multiple levels of headers. Add clear headers and connect them to the right cells so screen readers can explain the table.
